# Parte 8 — UI sin imponer otro diseño

Esta carpeta NO trae un dashboard paralelo ni CSS de FlowZap.

Usa los modelos/catálogos dentro de los componentes que YA existen en tu CRM:

- `panel-client.tsx`
- `FlowEditor.tsx`
- tab `conversations`
- tab `crm`
- tab `settings`
- tab `billing`

La regla es: reutilizar tarjetas, botones, modales, tabs, colores, inputs y motion patterns existentes.

No crear `index.html`, layout propio, sidebar propio ni navegación propia.
